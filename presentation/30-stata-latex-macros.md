# 2. Stata → LaTeX

## The idea

[policy_macros.do]{.box} → [results_macros.tex]{.box} → [paper.tex]{.box} → [paper.pdf]{.box}

- Your do-file **writes** each number into a small file, as a LaTeX macro
- Your paper **reads** that file, and uses the macro instead of the number
- The number changes? Re-run, recompile. Done.

[Oswald (2026), "Are your in-text numbers correct?"](https://jpedataeditor.github.io/posts/20260910-latex-macros/)

## Step 1: Get the files

- On GitHub: [Code]{.menu} ▸ [Download ZIP]{.menu}, then unzip

  - `paper.tex`: the paper

## Step 2: Open Stata, go to the folder

Menu: [File]{.menu} ▸ [Change Working Directory...]{.menu}, pick the folder.

Or type, in the Command window:

```stata
cd "C:/Users/you/Downloads/reproducible-documents-main/examples/02-stata-latex-macros"
```

Check with `pwd`, and `dir` should list `policy_macros.do`.

## The do-file: compute

```{r, echo=FALSE, results='asis'}
show_file("examples/02-stata-latex-macros/policy_macros.do", from = "// ---- Policy A", to = "if pct_change_A", lang = "stata")
```

## The do-file: numbers to text

```{r, echo=FALSE, results='asis'}
show_file("examples/02-stata-latex-macros/policy_macros.do", from = "// ---- format every number", to = "local nreassB", lang = "stata")
```

- `string(x, "%4.1f")`: the number, as text, with one decimal
- `strtrim()`: remove the leading space

## The do-file: open the file

```{r, echo=FALSE, results='asis'}
show_file("examples/02-stata-latex-macros/policy_macros.do", from = "// ---- open the macro file", to = "% Generated", lang = "stata")
```

- `file open ... write replace`: create the file (or overwrite it)
- `_n`: a new line

## The do-file: write the macros

```{r, echo=FALSE, results='asis'}
show_file("examples/02-stata-latex-macros/policy_macros.do", from = "// percentages", to = "PreferredPolicy", lang = "stata")
```

## The do-file: a real regression

## Step 3: Run it

Open `policy_macros.do` in the Do-file Editor, click [Do]{.menu}. Or type:

```stata
do policy_macros.do
```

The last line shows you the file it wrote: `results_macros.tex`.

## The result: `results_macros.tex`

```{r, echo=FALSE, results='asis'}
show_file_or("examples/02-stata-latex-macros/expected/results_macros.tex",
  fallback = paste(
    "```latex",
    "% Auto-generated by policy_macros.do -- do not edit by hand.",
    "% Generated: 10 Sep 2026 17:42:46",
    "",
    "\\newcommand{\\WelfareA}{2.3\\%}",
    "\\newcommand{\\WelfareB}{1.1\\%}",
    "",
    "\\newcommand{\\NReassA}{64}",
    "\\newcommand{\\NReassB}{12}",
    "",
    "\\newcommand{\\PreferredPolicy}{A}",
    "% ... plus \\CoefMpg, \\SeMpg, \\NObs from the regression",
    "```", sep = "\n"),
  lang = "latex")
```

**Do not edit by hand.** Re-run the do-file instead.

## The paper: `paper.tex`

```{r, echo=FALSE, results='asis'}
show_file("examples/02-stata-latex-macros/paper.tex", from = "% None of the numbers", to = "\\input", lang = "latex")
show_file("examples/02-stata-latex-macros/paper.tex", from = "In our experiment", to = "holding weight constant", lang = "latex")
```

## Step 4: Compile the paper

No LaTeX on your laptop? Use [Overleaf](https://www.overleaf.com) (free):

- [New Project]{.menu} ▸ [Upload Project]{.menu}
- Upload a ZIP with `paper.tex` **and** `results_macros.tex`
- Click [Recompile]{.menu}

With LaTeX installed: open `paper.tex` in TeXworks or TeXShop, click [Typeset]{.menu}.

## Step 5: Change something

1. In `policy_macros.do`, change `102.3` to `100.5`
2. Re-run the do-file
3. Upload the new `results_macros.tex` to Overleaf (replace the old one), recompile

The text now says policy **B** is preferred. You did not touch `paper.tex`.

## Checklist

- Every number in the text (abstract, intro, footnotes, slides) is a **macro**
- The macro file says "do not edit by hand", and when it was generated
- The macro file is **re-created** every time you run your code
- The macro file is part of your **replication package**
- Your slides `\input` the **same** macro file
